# IT Infrastructure & Networking Labs

This repository contains practical labs demonstrating fundamental IT infrastructure and networking skills.

## Project: VM Network Connectivity
In this lab, I successfully configured two virtual machines (VMs) using VMware to communicate with each other.

### Key Achievements:
* Configured static IP addresses for each virtual machine.
* Established a stable network connection between the two hosts.
* Verified connectivity using the `ping` command with 0% packet loss.
